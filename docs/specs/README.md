# Specs

Design specs for this project live here.

Format: `docs/specs/NNNN-title.md`, where `NNNN` is a zero padded sequence number and `title` is a short kebab case slug.

Status: no spec has been written yet. Features ship directly from the scope in `docs/scope/` and the conventions in `AGENTS.md`.

Write a spec when a load bearing design decision needs to be recorded before building. Do not invent specs for work that has no open design decisions.
